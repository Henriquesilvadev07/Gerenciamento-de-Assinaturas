Sistema para gerenciamento de pagamentos recorrentes e assinaturas mensais. A aplicação controla o ciclo de vida de cada serviço,
calculando automaticamente o status do pagamento (em dia, atrasado ou suspenso) com base na data de vencimento, 
além de exibir o valor total das faturas e o montante total em atraso, facilitando o acompanhamento de gastos fixos e evitando surpresas com bloqueios.

Tecnologias Utilizadas:
Java 21
Spring Boot 3
Front-end: HTML, CSS e JavaScript
